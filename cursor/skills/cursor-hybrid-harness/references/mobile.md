# Mobile-policy activation

Load this reference only for Android, iOS, Swift, Kotlin, Kotlin Multiplatform,
Jetpack Compose, Android Views, SwiftUI, UIKit, Gradle mobile, or Xcode work.
For those tasks, load and follow the installed canonical mobile policy at
`~/.agents/skills/mobile-template-engineering/v1`, including its applicable
Android and/or iOS/KMP gates, routing, risk floors, approval requirements,
templates, scope control, Git policy, and verification rules.

Those gates may raise complexity or require explicit human approval. They never
apply to unrelated web, backend, documentation, or scripting work. This Cursor
skill does not modify the canonical mobile policy or replace more-local project
authority. The canonical policy's role sequencing, risk floors, approval gates,
templates, scope control, Git policy, and verification evidence remain in force;
its Codex-specific model names are adapted to the Cursor Hybrid pool matrix in
`references/routing.md`. Do not dispatch Codex-only Luna/Terra/Sol/Astra model
names from Cursor. If Team or project policy conflicts with this adaptation,
stop and escalate instead of choosing a model by assumption.
